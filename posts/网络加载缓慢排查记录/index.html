    简介#

    最近在使用 Edge 浏览器时发现国内网站（抖音、B站）加载异常缓慢，视频加载需要几十秒甚至完全无法播放。通过 Wireshark 抓包分析，最终定位到问题根源并找到了解决方案。

    问题现象#

    • 抖音网页版：页面加载需要 40+ 秒，视频几乎无法播放
    • B站：页面加载后视频完全无法加载，显示"响应时间过长"
    • 其他国内外网站也有不同程度的加载缓慢

    排查工具#

    使用 Wireshark 的命令行版本 tshark 进行抓包分析，主要命令：

    # 协议分布
tshark -r 文件.pcapng -q -z io,phs

# 每秒流量统计
tshark -r 文件.pcapng -q -z io,stat,1

# TLS 连接域名
tshark -r 文件.pcapng -Y "tls.handshake.extensions_server_name" -T fields -e tls.handshake.extensions_server_name

# SYN 重传目标
tshark -r 文件.pcapng -Y "tcp.flags.syn == 1 && tcp.analysis.retransmission" -T fields -e ip.dst

# TCP 连接统计
tshark -r 文件.pcapng -q -z conv,tcp

    排查过程#

    第一阶段：Google Safe Browsing 的"隐形杀手"#

    第一次抓包发现，Edge 的 Safe Browsing 功能在后台不断尝试连接 Google 服务器：

    172.217.119.4  → 34 次 SYN，0 次响应
172.217.118.4  → 18 次 SYN，0 次响应

    这些 SYN 重传占用了大量 TCP 连接槽，导致抖音的正常连接被阻塞。

    解决方案：关闭 Edge SmartScreen（设置 → 隐私 → 安全浏览 → 关闭）

    第二阶段：IPv6 路由不通#

    更换阿里 DNS 后，DNS 解析速度正常（20-90ms），但视频 CDN 连接仍然很慢。分析发现：

    • 抖音视频 CDN 分配了大量 IPv6 地址
    • 但 IPv6 到这些地址的路由不通
    • SYN 重传 161 次，每个视频连接都经历多次失败才成功

    解决方案：暂时关闭 IPv6，强制走 IPv4

    第三阶段：B站 的 Cloudflare 绕路问题#

    关闭 IPv6 后抖音正常了，但 B站 仍然无法加载视频。路由追踪发现：

    本机 → 电信 163 骨干网 → 美国圣何塞 (NTT) → 香港 → Cloudflare
总延迟：280ms+

    B站 使用了 Cloudflare 代理（103.151.151.x），被路由到了海外节点，TCP 握手需要 7-8 秒（正常应 <100ms），视频 API 请求超时。

    第四阶段：Edge DoH 的双刃剑#

    进一步分析发现，Edge 的 DNS-over-HTTPS（DoH）功能使用 chrome.cloudflare-dns.com，这个地址在部分时段连接不稳定：

    chrome.cloudflare-dns.com → 86 次 SYN 重传

    导致 DNS 查询超时，浏览器使用了缓存的旧 IP（Cloudflare 海外节点）。

    最终解决方案#

    经过多次抓包对比测试，找到了最佳配置：

    设置项配置值作用
    系统 DNS 首选223.5.5.5（阿里）国内域名解析快
    系统 DNS 备用1.1.1.1（Cloudflare）国外域名解析
    Edge DoH使用当前服务提供商国外网站 CDN 加速
    IPv6保持开启B站等走 IPv6 国内节点
    Edge SmartScreen关闭减少无用连接

    配置步骤#

    1. 设置系统 DNS

    # 以管理员身份运行
netsh interface ipv4 set dnsservers "以太网" static 223.5.5.5
netsh interface ipv4 add dnsservers "以太网" 1.1.1.1 index=2

    2. 关闭 Edge SmartScreen

    edge://settings/privacy → 安全浏览 → 关闭

    3. 保持 Edge DoH

    edge://settings/privacy → 使用安全的 DNS → 使用当前服务提供商

    4. 刷新 DNS 缓存

    ipconfig /flushdns

    效果对比#

    指标优化前优化后
    抖音视频加载41 秒开始6 秒开始
    B站视频加载完全无法加载8 秒开始
    TCP 重传率11.8%<5%
    B站 主站延迟280ms+（绕美国）<50ms（IPv6 直连）

    关键发现#

    1. 被墙服务的 SYN 重传是隐形杀手#

    每次 SYN 重传都占用 TCP 连接槽和系统资源。即使你没有主动访问 Google/Facebook，Edge 的后台服务也会不断尝试连接，拖慢所有正常网站。

    2. DNS 只解决解析，不解决路由#

    更换 DNS 可以让域名解析到正确的 IP，但如果 ISP 的路由到这个 IP 绕路了，DNS 也无能为力。

    3. IPv6 不要轻易关闭#

    很多国内网站（B站等）的 IPv6 国内节点比 IPv4 更快。关闭 IPv6 可能导致浏览器回退到 IPv4 的 Cloudflare 海外节点。

    4. Cloudflare 代理可能适得其反#

    国内网站使用 Cloudflare CDN 反而比直连慢，因为流量可能被路由到海外节点。

    常用网络诊断命令#

    # 刷新 DNS 缓存
ipconfig /flushdns

# 查看 DNS 解析
nslookup 域名 223.5.5.5

# 路由追踪
tracert IP地址

# 查看网络配置
ipconfig /all

# 重置网络（管理员权限，需重启）
netsh winsock reset
netsh int ip reset

    总结#

    这次排查的核心教训：Edge 浏览器的各种后台服务（Safe Browsing、DoH、遥测）在国内环境下可能成为性能瓶颈。通过合理的 DNS 配置和关闭不必要的安全检查，可以在不牺牲太多安全性的情况下大幅提升浏览体验。
