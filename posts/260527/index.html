    ## 简介

    这篇文章总结了我学习 Linux 过程中最常用的命令。

    ## 文件操作

    
\# 1. ls — 看看当前目录有什么

ls

ls -l          # 详细信息（权限、大小、日期）

ls -la         # 包括隐藏文件



\# 2. cd — 进入某个目录

cd /etc        # 进入 /etc 目录

cd \~           # 回到家目录

cd ..          # 回到上一级

cd /           # 回到根目录



\# 3. pwd — 我现在在哪个目录

pwd

\# 输出类似：/home/yourname



\# 4. mkdir — 创建文件夹

mkdir myfolder



\# 5. touch — 创建空文件

touch myfile.txt



\# 6. cp — 复制文件

cp myfile.txt myfile\_backup.txt



\# 7. mv — 移动/重命名文件

mv myfile.txt newname.txt        # 重命名

mv newname.txt myfolder/         # 移动到文件夹



\# 8. rm — 删除文件

rm myfile\_backup.txt

rm -r myfolder          # 删除文件夹（-r 表示递归）



\# 9. cat — 查看文件内容

echo "hello linux" > test.txt    # 写入内容到文件

cat test.txt                     # 看看里面写了什么



\# 10. clear — 清屏

clear
